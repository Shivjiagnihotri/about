# Learning garden: book research and link verification

Checked on **2026-10-09 UTC**. Catalogue: **18 books or distinct volumes**, comprising **14 PDF resources** and **4 online books**. Six PDF entries also provide notebooks through their official source page. Descriptions are original summaries, not copied publisher blurbs. Levels are editorial guidance, not prerequisites stated by every author.

## Selection and access

The catalogue uses author websites, university pages, official project repositories, and author-submitted arXiv manuscripts. It links out to the authorized resource; it does not redistribute book files, cover art, or text. Free access does not imply an open redistribution license. Where the freely available edition is a draft or a notebook edition, the description says so. Publication years are distinguished from draft years.

HTTP checks used Python `urllib.request` with a browser user agent and a `Range: bytes=0-1023` request. A `206` status is the expected partial-content response. PDF checks read the returned bytes and checked for `%PDF-`, rather than inferring file type from a suffix. Sources were also inspected with web browsing for authorship, scope, publication details, and permission. PDF verification is a link health check, not a full editorial review of each book.

## Important implementation details

- Do not replace the current ISLP or ESL URLs with their former `.pdf` paths at hastie.su.domains. Both former direct paths returned HTTP 404. The author's current links intentionally route to Google Drive.
- GitHub and Google Drive may deliver PDF bytes with `application/octet-stream` or attachment headers. A normal link opens the resource in a new tab, but the user's browser and the origin server ultimately determine whether it displays or downloads. Do not promise an embedded viewer for those links.
- The catalogue is curated data fetched during research, not a live client-side scraper. This avoids fragile CORS dependencies and rate-limited GitHub requests during page load. The exported `booksCheckedAt` value records when these links were checked.
- `PDF + notebooks` means the main action opens the PDF while the accompanying source link leads to the author's page with notebooks. It is not a bundled download.
- No third-party scans, paid-only editions, sample-only PDFs, or unlicensed mirrors were included. Goodfellow and Bishop remain authorized online reader links. The fast.ai entry is the author's notebook edition.
- Classic books remain useful for fundamentals, but examples may rely on old software versions. The catalogue describes conceptual scope rather than claiming every historical code example works with present-day packages.
